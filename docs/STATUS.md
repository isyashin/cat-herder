# Состояние Cat Herder

Дата среза: 23.10.2026.

## Принято

Публичная основа «Пастуха кошек»: документация процесса, выбор моделей, исторический дневник пилотов, измерения, шаблоны контрактов и примеры OpenCode v2.0.30. Ключи, профили провайдеров, рабочие prompts, полные сессии, логи и файлы игр не включаются.

## В работе / очередь

Первый срез подготовлен для отдельного публичного репозитория. Следующая техническая работа — переносимый runner по [ROADMAP.md](ROADMAP.md). Код исполнителя не назначен; автоматические повторяющиеся задачи не запущены.

## Ограничения

Исторические оценки моделей не гарантируют сегодняшнюю доступность. Windows-runner опубликован как текст для аудита и содержит известные ограничения ACL; готовой строгой изоляцией он не считается. Docker-контур не испытан. Общая методика уже применялась в пилотах, переносимость инструментов предстоит проверить отдельно.
