# Дневник моделей OpenCode

Обновлено: 20 октября 2026 года. Оценки относятся к работе **через текущую конфигурацию OpenCode** в проектах Tetris и «Луми и лабиринты». Это не общий рейтинг моделей. После каждого задания дописывать дату, ID, результат проверки, нарушение границ, число исправлений и наблюдаемый расход. Ошибку доступа или квоты не выдавать за низкое качество кода.

Шкала практической оценки: **5** — принято с первого прохода на нескольких задачах; **4** — принято на узкой задаче, иногда после одной правки; **3** — полезный результат с заметными затратами на исправление; **2** — только простые файлы под строгой проверкой; **1** — на проверенном типе задачи нет принятого результата; **—** — качество пока не измерено. При одном опыте оценка предварительная. Исходные логи — `.agent-runtime/`; приёмка определяется Git diff и тестами, а не словами агента.
