# Где искать бесплатные маршруты

Исторический снимок исследования 18–19.10.2026. Перед рабочим запуском сверяйте каталог, тариф, лимиты и правила обработки данных у провайдера. Наличие модели в каталоге не доказывает доступность аккаунту.

## Источники бесплатного доступа

| Источник | Что известно сейчас | Условие перед использованием |
| --- | --- | --- |
| [OpenCode Console](https://dev.opencode.ai/v2/docs/console/models/) | В каталоге есть модели с `-free`. В пилоте работала `nemotron-3-ultra-free`; `longcat-2.5-preview-free`, `mimo-v2.6-flash-free` и `deepseek-v4.1-flash-free` ответили `Rate limit exceeded` в пробах 18.10.2026. 20.10 пользователь сообщил о работе DeepSeek Flash 4.1; ID `opencode/deepseek-v4.1-flash-free` подтверждён локальным каталогом, 20.10 выполнена художественная переработка «Луми»: полезен на точных файловых контрактах, широкие задачи потребовали исправлений; см. дневник. Локальный `auth list` не показал явного подключения Console; способ доступа к free-маршрутам здесь не установлен. | Проверить актуальный каталог и квоту; использовать только официально подтверждённый free ID. [Команда OpenCode сообщает](https://github.com/anomalyco/opencode/issues/55136), что free-лимит серверный и переустановка его не сбрасывает. |
| [OpenRouter Free](https://openrouter.ai/pricing) | Free: 50 запросов в день и 20 в минуту для free-моделей; неудачные запросы тоже входят в суточный лимит. `thinkingmachines/inkling-small:free` завершила однофайловую пробу; Gemma 4 26B Free вернула ошибку провайдера. | Убедиться, что модель всё ещё `:free`, учесть политику данных конкретного маршрута. Free-тариф в таблице **не включает prompt caching**. |
| [Groq Free Plan](https://console.groq.com/docs/rate-limits) | Подключение есть в OpenCode. Публичная таблица Free Plan: `openai/gpt-oss-120b`, `openai/gpt-oss-20b` и `qwen/qwen3.8-27b` — по 30 RPM, 1 000 RPD, 8 000 TPM, 200 000 TPD. Кэшированные токены Groq не считает в лимиты. | Точные лимиты и остаток смотреть в кабинете Groq и заголовках ответа. `gpt-oss-120b` создал принятые тесты и UI, но два продолжения сессии упёрлись в 8 000 TPM. Давать один небольшой артефакт за вызов. |
| [Mistral Free mode](https://docs.mistral.ai/admin/billing-usage/usage-limits) | Подключение есть в OpenCode; пользователь проверил работу `mistral/codestral-2508` и подтвердил, что 18.10.2026 нет способа оплаты и pay-as-you-go. Free mode включает месячный объём; персональные ограничения скорости приведены ниже. | Не включать pay-as-you-go и автоматический платный fallback. Оставшийся включённый месячный объём неизвестен; высокая скорость сама по себе не означает безлимитных бесплатных токенов. |
| [Gemini API Free Tier](https://ai.google.dev/gemini-api/docs/pricing) | Пользователь подтвердил Free Tier без биллинга. `gemini-3.8-flash`, `gemini-3.5-flash-lite` и Gemma 4 имеют бесплатные вход/выход в Standard; первые две модели изменили файл в пилоте. | [Лимиты действуют на проект](https://ai.google.dev/gemini-api/docs/rate-limits), точные значения смотреть в AI Studio. Gemma 4 26B уже ответила 429 по метрике входных токенов с лимитом 16 000. На Free Tier содержимое запросов может использоваться для улучшения продуктов; закрытый код не отправлять без решения владельца. |
| [NVIDIA NIM Developer](https://docs.api.nvidia.com/nim/docs/product) | Бесплатные API-эндпоинты для разработки и испытаний. | Не использовать как производственный маршрут; проверить лимиты и совместимость OpenCode. |
| [Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/platform/pricing/) | 10 000 Neurons в день бесплатно, но ряд крупных моделей требует платный метод. | Проверить конкретную модель и расход Neurons; не активировать Workers Paid ради задачи. |
| [Cerebras promo](https://www.cerebras.ai/pricing) | Разовый кредит $5 на 30 дней после добавления платёжного метода; после исчерпания API останавливается без автоматической оплаты. | Это акция с платёжным методом, а не постоянный бесплатный тариф. Только если пользователь отдельно выберет этот вариант. |
| Локальные модели | Нет API-квоты, но нужны железо, память, электричество и настройка совместимого сервера. | После команды на настройку измерить качество и скорость на данной машине; не считать локальный запуск уже готовым. |

[Hugging Face Inference Providers](https://huggingface.co/docs/inference-providers/pricing) в текущих условиях **не входят** в бесплатный резерв: у Free Users указано `None` для месячных кредитов, требуются покупные кредиты. Интеграция с OpenCode существует, но не делает inference бесплатным. Другие промо рассматривать только с датой окончания, условиями и выключенным платным продолжением.
