# План развития

## Первый публичный срез

- [x] Отдельный Git-репозиторий Cat Herder.
- [x] Процесс, инструкции координатора и шаблоны.
- [x] Исторический дневник моделей и очищенные счётчики пилотов.
- [x] Примеры OpenCode v2 и текст Windows-прототипа с описанными ограничениями.

## Следующий этап — переносимый runner

1. Настраиваемые workspace, пути CLI, runtime и manifest schema без пользовательских абсолютных путей.
2. Проверка реальных путей, разрешённых изменений и base SHA до старта.
3. Общая блокировка запуска, живой вывод, индивидуальные тайм-ауты и машинный отчёт.
4. Точное сохранение/восстановление прав; тесты на ошибку старта, прерывание и уже существующие ACL.
5. Изоляция отдельным пользователем ОС либо контейнером, который не может менять основной проект и своё ограничение доступа.
6. Применение принятого патча отдельным действием координатора; проверка всего пакета до записи.

## После базового контура

- Каталог провайдеров/моделей с датой проверки, без автоматического платного fallback.
- Локальный журнал квот, cooldown после 429 и учёт общего бюджета провайдера.
- Сбор usage после полезных запросов, без отдельного прогрева ради метрик.
- Воспроизводимые небольшие задания для сравнения качества, скорости, границ diff и цены принятого результата.
- Сохранение task state/очереди, отчёты по приёмке и короткая передача следующему агенту.
- Обновление справки после изменения CLI и условий провайдеров с сохранением истории.

Автоматические регулярные проверки пока не настроены; расписание и частота требуют отдельного рабочего решения.
