# Исторический пакетный запуск OpenCode под Windows

[run-opencode-batch.ps1.txt](run-opencode-batch.ps1.txt) — текст прототипа из пилотов Tetris/Lumi. Личные пути заменены `<WORKSPACE_ROOT>` и `<OPENCODE_EXE>`. В рабочем прототипе проверялись отдельные клоны, параллельные процессы, живые stdout/stderr, индивидуальные тайм-ауты и пробный запрет записи в основные проекты.

Файл намеренно имеет расширение `.txt`. Он опубликован для изучения и переработки, а не как готовый установщик или sandbox. Известные проблемы: полномочия того же пользователя, неточная очистка существующих deny ACE, отсутствие общего lock и полноценной проверки reparse points, зависимость восстановления от finally.

Перед реализацией исполняемого runner нужны требования и испытания из [ISOLATION.md](../../docs/ISOLATION.md) и [ROADMAP.md](../../docs/ROADMAP.md). Изменения прав проверяются только на временных тестовых репозиториях.
