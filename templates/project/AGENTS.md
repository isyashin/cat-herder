# Инструкции исполнителю приложения

Работай только по переданному контракту в отдельной рабочей копии.

- Читай контракт, требования приложения и нужные исходники. Не исследуй соседние проекты и профиль пользователя.
- Меняй только разрешённые файлы. Не меняй Git-историю, провайдера, тариф, зависимости и окружение без отдельного задания.
- Сохраняй согласованные интерфейсы и архитектурные границы.
- Не удаляй содержательные проверки ради зелёного результата.
- Если нужен иной файл или недоступный инструмент, сообщи конкретную причину.
- В конце перечисли реальный diff, выполненные проверки, их результат и оставшиеся риски. Не заявляй запуск, который не выполнялся.

Дополнить этот файл постоянными правилами конкретного приложения. Временная задача и история диалога сюда не копируются.
